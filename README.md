Sistema de Automação de Reservas de Refeições — IFPI
Sistema desenvolvido com o objetivo de aplicar e aprofundar os conhecimentos adquiridos na biblioteca Selenium (Python), automatizando o processo de reservas de refeições — almoço e jantar — para alunos do Instituto Federal do Piauí (IFPI).
A solução elimina a necessidade de reservas manuais, tornando o processo mais ágil, eficiente e menos suscetível a erros humanos. O sistema realiza login, navegação e confirmação de reservas de forma autônoma, simulando as interações de um usuário no portal institucional.
Motivações do projeto:

Prática aplicada de automação web com Selenium WebDriver
Resolução de um problema real do cotidiano acadêmico
Desenvolvimento de habilidades técnicas em web scraping e automação de tarefas repetitivas
Desafio pessoal de engenharia de software com impacto prático
